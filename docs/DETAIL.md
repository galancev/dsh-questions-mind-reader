# Вопросы в мыслях

Показывает вопросы, на которых модель застряла во время размышлений, всплывающими пузырями над полем ввода. Ответ даётся прямо в пузыре и уходит модели на границе следующего шага — текущий шаг не прерывается.

## Что попадает в пузыри

Два источника, включённые по отдельности:

- **Метки модели.** В системный промпт добавляется короткий раздел (порядок 9500) с просьбой писать в рассуждении `[[ask]]короткий вопрос[[/ask]]`, а после самостоятельного решения — `[[done]]итог[[/done]]`. Такие пузыри помечены точкой и считаются точными.
- **Эвристики по тексту.** Предложения из рассуждения, похожие на вопрос (знак вопроса или слова сомнения), для ru/en/zh/ja/ko. Фрагменты кода, путей, URL и пересказ слов пользователя отбрасываются, повторы склеиваются.

## Использование

- Пузырь справа над вводом: клик — ответ, правый клик — весь текст (по умолчанию пять строк), × — скрыть. Шрифт пузыря берётся из `--dsh-content-font-size`, то есть совпадает с текстом переписки.
- Вопрос на другом языке переводится на `targetLang` через службу `ctx.translator` (её приносит `@deepseek-ai/dsh-experimental-cot-translation-bundle`); в пузыре показывается перевод, правый клик переключает оригинал и перевод. Без смонтированной службы вопрос показывается как есть.
- Ответ отправляется в сессию как `steer`: модель получит его на границе следующего шага, не прерывая текущий.
- Показываются только вопросы сессии, открытой в основной области. Субагенты и фоновые сессии не сыплют пузырями.
- Если модель начала писать ответ или вызывать инструмент, неотвеченные пузыри притухают: модель пошла дальше, но ответить ещё можно.

## Ограничения

- Показывается не больше `maxBubbles` пузырей (1–9, по умолчанию 3), текст вопроса обрезается до 160 символов, ответ — до 2000.
- Пузырь исчезает через `ttlSec` секунд (по умолчанию 60); наведение и открытый редактор продлевают его. `ttlSec: 0` отключает автоскрытие.
- Без стриминга рассуждений (`reasoning`) пузырей не будет вовсе.
- Эвристики ошибаются в обе стороны: пропускают часть вопросов и иногда показывают не-вопрос. Метки модели точнее, но зависят от её дисциплины.
- Ответ приходит только на границе шага: если ответить слишком поздно, он поможет уже не тому шагу.

## Конфигурация

Значения живут в `cordis.patch.yml` строки плагина:

| Ключ | По умолчанию | Смысл |
| --- | --- | --- |
| `enabled` | `true` | Показывать пузыри |
| `markers` | `true` | Просить модель помечать вопросы |
| `heuristics` | `true` | Ловить вопросы по тексту |
| `maxBubbles` | `3` | Сколько пузырей видно одновременно (1–9) |
| `ttlSec` | `60` | Автоскрытие, секунды; `0` — не скрывать |
| `gutterPx` | `160` | Пустая полоса справа от зоны чата под пузыри, px; `0` — выключить |
| `translateQuestions` | `true` | Переводить вопросы на `targetLang` |
| `targetLang` | `ru` | Целевой язык перевода |

Пузыри живут в правой полосе шириной `gutterPx`: отступ добавляется только зоне прокрутки диалога, поэтому шапка, табы, сайдбар и правая панель не двигаются, а колонка чата сужается и уезжает влево. Пузыри привязаны к правому краю этой зоны и переезжают вместе с ней, когда открывается правая панель.
